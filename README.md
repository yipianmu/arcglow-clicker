# 弧光连点器 · ArcGlow

Windows 悬浮连点器。每枚悬浮球绑定一个窗口，独立设置键鼠操作、间隔、延时、按住时间和重复次数。多枚球可收纳到同一个输出面板。

## 下载

下载 [v0.1.0 Windows 单文件](https://github.com/yipianmu/arcglow-clicker/releases/download/v0.1.0/ArcGlow-v0.1.0-Windows.exe)，双击即可打开。适用于配有 .NET Framework 4.8 的 Windows 10 和 11。

## 快速上手

1. 打开应用。首次运行会显示教程，可以在设置里重新打开。
2. 把未绑定的小球或设置卡上的准星拖到目标窗口，松手即绑定。鼠标操作以准星中心为落点。
3. 选好按键与间隔，点「开始这枚」。在输出进程里可单独暂停、继续或修改每枚连点。
4. 按 `F10` 启动或停止全部输出。点「−」收纳。按 `F9` 隐藏整套悬浮界面，再按一次恢复。快捷键被占用时，界面会显示可用组合键。

控制面板默认在小球旁打开。需要固定在拖动后的位置时，可以在设置里打开「记住拖动后的面板位置」。`F9` 会恢复隐藏前正在使用的面板位置。

收纳后，第一圈放四项，第二圈从正上方开始顺时针排五项。正在输出的任务会点亮自己在圆环上的弧段。点击弧段可单独打开对应设置，点击中央可展开全部。长按键名可以悬停查看。

小球和目标窗口共用弧光颜色与强度。多枚连点同时输出到同一个窗口时，边缘会显示交融的颜色。设置里可以调强度、保存配置或关闭默认开启的调试自动暂停。紧急停止键默认是 `Ctrl+Shift+F10`。布局和配置保存在 `%LOCALAPPDATA%\GlassClicker`。

启动连点、切换悬浮界面和编辑内容时有轻量的音效反馈。可以在设置里试听或关闭「界面音效」。点击采样来自 [哇！口袋](https://battle.yipianmu.online/)。

弧光通过 Windows 窗口消息向选定窗口发送输入。应用接收窗口消息的方式各有不同，请在目标软件里短时间试跑确认。

## 本地构建

在装有 .NET Framework 4.8 的 Windows 10 或 11 上，用 PowerShell 在仓库根目录运行下面的命令。

```powershell
.\Build.ps1
```

生成的 `dist\ArcGlow.exe` 是单文件应用，可直接启动。
